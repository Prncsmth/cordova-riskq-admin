# Cordova RISKQ Admin

Administrative dashboard for the Cordova RISKQ Geolocation-Based Emergency and Assistance Coordination System.

## Features

- Admin authentication
- Emergency monitoring
- Live map monitoring
- Responder management
- Responder application approval
- User management
- Emergency reports
- Announcements
- Audit logs
- System settings
- Real-time responder tracking

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Socket.IO
- PostgreSQL / Neon
- REST API
